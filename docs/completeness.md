## Traditional register, the problem, and what the software does now

The note sheet used to sit in a file until the merchandising manager signed it and the director signed it. People lost a day because the file was on the wrong desk. The screen keeps the same two signatures. The manager's step escalates to the director after one working day, and both actions are stored.

Gauge, colour, defect and machine lists used to live in different Excel files. They are one register per list, with Bangla names, and a disabled core module cannot hide them.
